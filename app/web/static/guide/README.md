# Guide screenshots

The export guide (`/guide`) shows these images when they exist and hides the figure when they do not:

- `01-skiley-login.png` - skiley.net/stats with the Spotify sign-in button
- `02-skiley-lists.png` - a Top Tracks list with the time range selector (4 weeks / 6 months / 12 months)
- `03-skiley-export.png` - the export (download) button for a list

Take them signed in to Skiley, crop to the relevant part, keep each under about 200 KB (PNG or JPG; change the extension in `guide.html` if JPG), and avoid showing personal details. Mike's own stats are already public in the test fixture, so his lists are fine to show.
